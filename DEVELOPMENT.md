# Development Guidelines

## Development principles

1. Understand before implementing.
2. Research official documentation first.
3. Keep modules independent.
4. Prefer simple and maintainable solutions.
5. Write tests alongside implementation.
6. Document architectural decisions.
7. Avoid unnecessary dependencies.
8. Review AI-generated code.

## Git conventions

- feat: new functionality
- fix: bug fixes
- docs: documentation
- refactor: code restructuring
- test: testing
- chore: maintenance

## Workflow

1. Create an issue or milestone.
2. Create a feature branch.
3. Implement a small, testable change.
4. Run tests and review.
5. Commit with a descriptive message.
6. Merge after verification.
