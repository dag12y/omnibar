## Known verification limits

- No aarch64 runtime validation or physical reboot/fresh-machine installation.
- Package lifecycle tests use a private fakeroot pacman database, skip dependency
  resolution, and reject scriptlets/hooks; they are not a bootable VM test.
- Saved layouts restore matching open windows, not application processes or an
  exact tiling tree. Monitor changes require saving again. Partial failures are
  reported rather than rolled back. Maximization requires targeted Lua dispatch.
