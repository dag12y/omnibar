# v0.2.0 release verification

Verified on 2026-11-13, x86_64 Omarchy 4.5.0, Hyprland 0.56.2, Qt 6.12.0.

## Candidate checks

- `go vet ./...` and `go test -race ./...` passed.
- All 161 QML tests passed.
- Private compositor tests passed for layouts (including exact controls),
  previews, unified search, app launching, and Clipboard/File shelf behavior.
- Layout checks covered floating geometry and workspace restoration, real UI
  Save, same-name replacement, private file permissions, restart persistence
  without automatic application, missing-window rejection, and deletion.
- Exact background controls retained unrelated windows and confirmed requested
  states. Preview tests used synthetic windows rather than host captures.
- Isolated audio, UI handshake/metrics/reconnect, and live Keep Awake tests passed.
- Working-tree Arch package build and its complete `check()` suite passed.

Tag-source package, asset checksums, lifecycle transactions, and installed-service
results are recorded after final release verification below.

## Known verification limits

- No aarch64 runtime validation or physical reboot/fresh-machine installation.
- Package lifecycle tests use a private fakeroot pacman database, skip dependency
  resolution, and reject scriptlets/hooks; they are not a bootable VM test.
- Saved layouts restore matching open windows, not application processes or an
  exact tiling tree. Monitor changes require saving again. Partial failures are
  reported rather than rolled back. Maximization requires targeted Lua dispatch.
