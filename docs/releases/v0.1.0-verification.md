## Isolated lifecycle evidence

`python3 scripts/verify-package-lifecycle.py OLDER_PACKAGE NEWER_PACKAGE` passed
baseline install, upgrade, same-version reinstall, downgrade, uninstall, and
reinstall after removal using fakeroot and a private pacman root/database.
Synthetic config, favorites, and state files remained byte-for-byte unchanged.
The baseline uses commit `8a1ef9f` packaged as `0.1.0-0`; downgrade restored its
exact backend digest. The final published package was used as the newer package.
The host installation was not downgraded or removed.

Dependency checks are skipped for this transaction test: it is not a bootable
VM and does not validate guest service startup or third-party package hooks.
Omnibar packages with scriptlets or libalpm hooks are rejected by the check.
Runtime integration is verified separately with the package UI and installed
service checks above.
