# v0.1.0 — 2026-11-13

Omnibar brings system monitoring and desktop utilities into one themed
Quickshell panel on Omarchy and Hyprland.

- Live CPU, RAM, swap, filesystem, disk I/O, network, and battery metrics.
- Playback volume/mute, output selection, per-stream output routing, microphone
  gain/mute/default input, and recording-app metadata.
- Explicitly started session clipboard history, saved text favorites, search,
  and Transform & copy utilities.
- A session File shelf for local references, folder opening, and path copying.
- Searchable running windows with confirmed switching across workspaces.
  Both legacy and Lua-configured Hyprland sessions are supported.
- Timed Keep Awake with system/display inhibition, countdown, and Stop.
- Keyboard controls, screen-bounded scrolling, live Omarchy theme colors, and
  automatic backend reconnection.

## Installation and permissions

Build with `make package`, install the resulting Arch package with
`sudo pacman -U dist/omnibar-0.1.0-1-x86_64.pkg.tar.zst`, and run
`systemctl --user enable --now omnibar.service` followed by `omnibar-ui`.
See [packaging](https://github.com/dag12y/omnibar/blob/main/docs/development/packaging.md) for dependencies and upgrades.

Existing configuration is preserved. Grant capabilities in your existing
`~/.config/omnibar/config.toml` and restart the backend to enable optional
features. Window switching requires `window.manage` and the Hyprland session
environment. Clipboard reading/writing and File shelf access have separate
grants. Clipboard collection starts paused on every backend session; only
explicitly saved favorites persist. Favorites are stored as unencrypted text.

## Current limits

GPU monitoring, metric history/alerts, application launching, window previews,
layouts, and non-Hyprland window switching are deferred. Window listing excludes
special workspaces. Microphone controls do not include recording-app routing or
live sound meters. File shelf references are session-only.

Release verification covers x86_64 on Omarchy 4.5.0 with Hyprland 0.56.2.
aarch64 is declared by the package recipe but has not been runtime-tested.

Download the x86_64 Arch package and `SHA256SUMS` from the release assets, then
verify with `sha256sum --ignore-missing -c SHA256SUMS` before installing.
The release also includes a PKGBUILD with the verified tag-source checksum.
